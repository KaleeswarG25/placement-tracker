# Cloud-Based Student Placement Tracker

A full-stack cloud-based placement tracking system for students and admins.

## Tech Stack

- React
- FastAPI
- PostgreSQL
- Docker
- AWS EC2
- GitHub Actions
- Nginx
- Prometheus
- Grafana

## Features

- Student login and registration
- Company tracking
- CGPA eligibility checker
- Application status tracker
- Interview status tracker
- DSA progress tracker
- Resume upload
- Admin company management
- Dashboard analytics
